# Tidy Mapping

Teams:

This week we are going to make a map, and create a github pages site to put that map on.

## Data

We're using [house price and rental price data available from the ONS](https://www.ons.gov.uk/releases/privaterentandhousepricesukoctober2026). This includes historic data going back a few years for house prices and rental prices in a number of geographic areas in the UK.

Both Flourish and DataWrapper have some nice mapping templates. Find something in the data and create one or more maps.

## Deliverable

Embed the maps you create in a webpage, and create a new repository on github to put the code in. Publish this webpage using [Github Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).
