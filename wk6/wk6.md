This week we have data by postcode, and we would like to produce some maps of this data, as we did last week. However, postcode boundaries at a very local level are not available freely in the UK, so we will need to do something different to display this data

We can get postcode 'centroids', that is the central point of each postcode area from the ONS. **[Here is a set of postcode centroids for Cardiff]()**. Once we have the central points we can use that to add some data to a map, perhaps by:
1. using a shape at each point, which could be coloured or sized (or both) according to the data
2. using an algorithm (such as a voronoi) to create shapes around the points that *estimate* the area covered by the postcode
3. something else? what can you think of?

Create a map with this postcode data!
